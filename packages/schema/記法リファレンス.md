# Next Novel Maker 台本の書き方(記法リファレンス)

- 版数: v1.0(設計書 v0.4 の3章に準拠)
- 対象読者: シナリオ書き手。メモ帳でも書けます
- このファイルは AI草案生成のシステムプロンプトにもそのまま使われます

---

## 1. まず全体像

台本は普通のテキストファイル(`〇〇.scenario.txt`)です。最小の完全な例:

```
@title: あいさつテスト
@grade: 3
@theme: adv
@version: 1

# scene: main
@bg 教室
アミ(笑顔): おはよう!
タケル: …おう。
* 元気に返す -> genki
* だまっている -> damaru

# scene: genki
@set kizuna += 1
アミ(笑顔): 今日もいい天気だね!
@jump owari

# scene: damaru
アミ(焦り): あれ、どうしたの?
@jump owari

# scene: owari
@emit result
@end
```

## 2. 基本ルール(5つだけ覚える)

1. **1行 = 1つのこと**(1セリフ、1命令)
2. **記号は全角・半角どちらでもOK**(`：`と`:`、`＊`と`*`、`→`と`->` … 同じ意味。9章の対応表参照)
3. **行頭の字下げ(スペース・タブ)は自由**。見やすさのためだけで、意味は変わらない
4. **書かなくていいものは書かない**。表情・立ち位置は前の状態が続く(変えたいときだけ書く)
5. 間違えても大丈夫。**エラーは行番号つきで全部まとめて**教えてくれる

## 3. ファイルの構成

### 3.1 メタヘッダー(ファイルの先頭に書く)

```
@title: 写真、勝手にアップしていいの?
@grade: 4                       # 対象学年(ルビの基準。1〜6)
@theme: sns                     # 既定テーマ(adv または sns。実行時に上書き可)
@version: 1
```

- `@grade` を書かないと自動ルビが働かない(警告が出る)

### 3.2 シーン

```
# scene: intro
```

- 台本は1つ以上の「シーン」でできている。シーン名(`intro` の部分)は**英数字とアンダースコア**のみ
- 選択肢の飛び先(`->`)や `@jump` はこのシーン名を指す

## 4. セリフと地の文

### 4.1 セリフ(発話)

```
アミ(笑顔): タケルくん、その写真アップしちゃうの?
タケル: 別にいいだろ!
```

- 形は `話者(表情): セリフ`
- **話者名**はキャラ定義(`content/characters/*.yaml`)の `name` と一致させる。定義にない名前はエラー
- **(表情)は省略可**。省略すると前の表情のまま。使える表情名もキャラ定義で決まっている(ないものはエラー)
- 未登場のキャラがしゃべると**自動で登場**する(いちいち `@enter` しなくてよい)

### 4.2 地の文(話者なしのナレーション)

```
: 次の日の朝。
ナレーション: 次の日の朝。
```

どちらの書き方でもよい。

## 5. 選択肢

```
* 「ちょっと待って」と言う -> stop_him
* 何も言わない -> ignore
```

- 形は `* 選択肢テキスト -> 飛び先シーン名`
- `*` で始まる行が連続すると、1つの選択肢グループとして画面に出る
- 飛び先のシーンが存在しないとエラー

## 6. 変数と条件分岐

### 6.1 変数を変える `@set`

```
@set trust += 1        # 1増やす
@set trust -= 1        # 1減らす
@set name = "タケル"   # 代入(数値・文字列・真偽が使える)
```

- **変数は宣言不要**。まだ一度も使っていない変数は「数値の 0」として扱われるので、いきなり `@set trust += 1` と書いてよい(0 + 1 = 1 になる)
- 型は最初の代入で決まる。文字列の変数に `+= 1` などをするとエラー

### 6.2 条件で分ける `@if` / `@else` / `@endif`

```
@if trust >= 1
  アミ(笑顔): 今日は良い勉強になったね。
@else
  アミ(焦り): あとで大変なことになるかも…。
@endif
```

- 条件式は `変数 比較 値`。比較は `==` `!=` `>=` `<=` `>` `<`
- 入れ子(ネスト)は最大3段まで
- `@endif` を忘れるとエラー
- **`@if` の中に選択肢 `*` は書けない**(エラー)。条件で選択肢を変えたいときは、`@if` + `@jump` でシーンごと分ける:

```
# scene: bunki
@if trust >= 1
  @jump erabu_yasashii
@endif
@jump erabu_kibishii
```

## 7. 画面と進行の命令

| 書き方 | 意味 |
|---|---|
| `@bg 教室` | 背景を変える |
| `@enter アミ left` | 立ち絵を出す(位置は `left` / `center` / `right`)。※発話で自動登場するので通常は不要 |
| `@exit アミ` | 立ち絵を消す |
| `@move アミ center` | 立ち位置を変える |
| `@jump ending` | 指定シーンへ飛ぶ |
| `@emit result` | 今の変数一式を外部(親ページ等)へ送る。イベント名は自由 |
| `@end` | シナリオ終了 |
| `// メモ` | コメント。画面には出ない(行の先頭に書く) |

## 8. ルビ(ふりがな)

```
アミ: その|写真《しゃしん》アップしちゃうの?
```

- 青空文庫記法 `|漢字《かんじ》`。`|` から `《` の直前までが対象、`《》` の中が読み
- `@grade` までに習わない漢字には**自動でルビが付く**が、固有名詞などの読み間違いは、この手動ルビで上書きするのが正解(手動が常に優先)
- 未習漢字にルビ指定がないと警告が出る(エラーではない)

## 9. 全角・半角はどちらでもよい(対応表)

構文の記号は全角で打っても半角で打っても同じ意味。日本語入力のまま書いてOK。

| 半角 | 全角 |
|---|---|
| `:` | `：` |
| `()` | `（）` |
| `*` | `＊` |
| `->` | `→` |
| `\|` | `｜` |
| `@` | `＠` |
| `#` | `＃` |
| `//` | `／／` |
| `\` | `＼`・`￥` |

- `《》` は全角のみ(青空記法どおり)
- セリフ本文の中の記号は変換されず、書いたとおり表示される

## 10. エスケープ(記号をただの文字として出す)

記号を「命令」ではなく「ただの文字」として画面に出したいときは、直前に **＼** を置く。

```
アミ: この記号＼|は「ルビの始まり」という意味だよ。
アミ: 山かっこ＼《かんじ＼》も、そのまま書けるよ。
* 「A＼->B」の意味をきく -> kigou
```

- ＼は半角 `\`・全角 `＼`・円マーク `￥` のどれで打ってもよい
- ＼＼ と2回書くと ＼ 自身が1つ出る
- ＼の後ろが記号でないとき(「￥500」など)は、そのまま表示される。エラーにはならない
- エスケープが必要なのは「その場所で命令と解釈される記号」だけ。行の途中の `*` などは、もともとただの文字なので何もしなくてよい

## 11. ありがちなエラーと直し方

| エラー・警告 | 原因と直し方 |
|---|---|
| 未定義シーンへのジャンプ | `->` や `@jump` の飛び先シーン名の打ち間違い。`# scene:` の名前と一致させる |
| 未定義キャラの発話 | 話者名がキャラ定義にない。`content/characters/` の `name` を確認 |
| キャラ定義にない表情名 | `(笑顔)` などがそのキャラのYAMLの `expressions` にない。表情名は日本語で統一 |
| `@if` の閉じ忘れ | `@endif` を足す |
| `@if` の中に選択肢 | v1では書けない。シーンを分けて `@jump` で振り分ける(6.2参照) |
| 未習漢字にルビなし(警告) | `|漢字《かんじ》` を付けるか、ひらがなに開く |
| 一度も `@set` していない変数を `@if` で見ている(警告) | たいてい変数名の打ち間違い。`@set` した名前と一致させる |
| 到達不能シーン(警告) | どこからも飛んでこないシーン。書きかけなら放置してよい(エラーにはならない) |

エラーは「ファイル名:行番号: メッセージ」の形で、**全部まとめて**報告される(最初の1個で止まらない)。

## 12. 構文早見表

| 構文 | 意味 |
|---|---|
| `@key: value`(ファイル先頭) | メタヘッダー(title / grade / theme / version) |
| `# scene: <id>` | シーン定義(`<id>` は英数字と `_`) |
| `話者(表情): セリフ` | 発話。表情は省略可 |
| `: セリフ` / `ナレーション: …` | 地の文 |
| `* テキスト -> <scene_id>` | 選択肢(連続する `*` 行が1グループ) |
| `@set <var> <op> <value>` | 変数操作(`=` `+=` `-=`) |
| `@if <条件>` / `@else` / `@endif` | 条件分岐(ネスト最大3段。中に選択肢は不可) |
| `@jump <scene_id>` | シーンへジャンプ |
| `@bg <背景ID>` | 背景変更 |
| `@enter <キャラ> [left\|center\|right]` | 立ち絵登場(通常は自動登場で足りる) |
| `@exit <キャラ>` | 立ち絵退場 |
| `@move <キャラ> <位置>` | 立ち位置変更 |
| `@emit <イベント名>` | 外部連携イベント発火(変数一式を添付) |
| `@end` | シナリオ終了 |
| `// コメント` | 行コメント |
| `\|漢字《かんじ》` | 手動ルビ(自動ルビより優先) |
| `＼<記号>` | エスケープ(`＼＼` で ＼ 自体) |
