# キャラ定義の書き方(キャラYAMLリファレンス)

- 版数: v1.0(設計書 v0.4 の4章に準拠)
- 置き場所: `content/characters/<id>.yaml`(1キャラ1ファイル)

## 1. 完全な例

```yaml
id: ami
name: アミ                # 台本で使う話者名
persona: >                 # AI草案生成時にプロンプトへ挿入する性格メモ
  小4女子。明るく面倒見が良い。相手を頭ごなしに否定せず、一緒に考える話し方。
default: ふつう            # 登場時の表情
position: left             # 登場時の立ち位置(left / center / right)
expressions:
  ふつう:  ami_normal.png
  笑顔:    ami_smile.png
  怒り:    ami_angry.png
  焦り:    ami_sweat.png
  悲しみ:  ami_sad.png
```

## 2. ルール

- **`name` が台本の話者名**。台本で `アミ(笑顔): …` と書いたら、この `name: アミ` のキャラが `笑顔` の表情でしゃべる
- **表情名は日本語で統一**する(英語名と混ぜない。画像ファイル名は英語のままでよい)
- `expressions` に書いた表情名だけが台本で使える。書いていない表情を使うとエラー
- 画像はこのYAMLと同じフォルダ(`content/characters/`)に置く。**透過PNG、高さ1024px推奨**(高さ基準で統一)
- SNS風テーマでは表情画像を正方形に切り出してアイコンに使う。切り出し位置を変えたいときだけ `icon_crop` を指定(省略時は上部中央):

```yaml
icon_crop: center          # 例: 顔が画像の中央にあるキャラ
```

## 3. 既存キャラの流用

お助けネットクラウドの既存差分(アミ・タケル等)を使う場合は、画像をこのフォルダに置いて、YAMLに表情名を起こすだけで移行完了。
